CSS Overrides

Some visual aspects of the Novix Switch can be customized with plain CSS. The following CSS variables are available for override.

Variable
Description
--novix-switch-true-background-color
Defines the background color of the switch in 'true' state.
--novix-switch-false-background-color
Defines the background color of the switch in the 'false' state.
--novix-switch-track-border-color
Sets the border color that is used surrounding the switch.
--novix-switch-thumb-color
Sets the color of the thumb (moving part) of the switch.

📖 Basic Usage

Using the Novix Switch is quick and straightforward. Start by importing the NovixSwitchModule, then drop a <novix-switch /> into your template.

To make it functional, bind it to a boolean property in your component-without that, it's just a pretty toggle with no state behind it.

The Novix Switch can be bound to a plain boolean property for simple on/off state, or to an Angular signal if you want full reactivity. Using a signal means the switch will automatically update whenever the signal changes, and toggling the switch will push updates back into your reactive state without extra wiring.

Properties

The following properties let you customize the Novix Switch. Bolded options are the default values.

Property
Type
Options
Description
checked
boolean
Reactive boolean state of the switch. Bind it to a plain boolean or an Angular signal for two-way updates. NOTE: Make sure to bind with "banana-in-basket" format, i.e. [(checked)].
config
INovixSwitchConfiguration
Optional configuration object that predefines the values below. Useful for re-using common settings across multiple switches without repeating them each time.
uiMode
string
horizontal | vertical
UI Mode to use, horizontal for a pill switch, and vertical for a mechanical toggle.
rounded
boolean
true | false
Whether to display the switch with rounded borders, otherwise squared.
trueBackgroundColor
string
--novix-primary
Background color of the switch when set to 'true'.
falseBackgroundColor
string
--novix-neutral-variant
Background color of the switch when set to 'false'.
trackBorderColor
string
--novix-neutral
Border color for the switch track.
thumbColor
string
--novix-surface-variant
Color of the thumb of the switch that moves.

Novix Switch Component

The Novix Switch is a drop‑in replacement for a standard checkbox, designed to give your UI a cleaner, more modern look. It’s fully reactive, so it works seamlessly with dynamic data and state changes, but its main purpose is presentation—making toggles feel polished without changing the underlying behavior of a checkbox.

♻️ Reusable Configuration

The Novix Switch is a lightweight replacement for a standard checkbox and can be used throughout a page or form. To simplify setup, we provide two configuration options that let you avoid repeating the same settings across multiple switches.
